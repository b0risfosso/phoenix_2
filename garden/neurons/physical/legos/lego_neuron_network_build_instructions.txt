LEGO Build Instructions: Neuron Network Model

Project Goal

Build a simple LEGO model of a neuron network. The model shows how signals move from input neurons through connected neurons to an output neuron. It can be used as a physical explanation of dendrites, soma, axons, synapses, excitatory signals, inhibitory signals, and network activity.

Approximate Difficulty

Beginner to intermediate.

Approximate Build Time

30 to 60 minutes.

Main Idea

Each neuron is built from:

- Soma: the main cell body
- Dendrites: short branches that receive signals
- Axon: a longer branch that sends signals away
- Synapse: the connection point between one neuron's axon and another neuron's dendrite
- Signal token: a small colored piece that can be moved by hand through the network

Suggested LEGO Pieces

Use any similar pieces available.

Neuron Bodies

- 5 to 8 round plates, dishes, or small circular builds for somas
- 2x2 round bricks, 2x2 round plates, or small wheel-like pieces work well
- Transparent pieces can represent active/glowing neurons

Dendrites

- Short bars, clips, hinges, antenna pieces, small plates, or 1x2/1x3 plates
- Use several short branches around each soma

Axons

- Longer plates, rods, bars, tubes, Technic axles, or connected 1x4/1x6 plates
- Axons should be longer than dendrites

Synapses

- Clips, small round studs, cones, or 1x1 plates at the end of each axon
- Leave a small gap between axon terminal and the next neuron's dendrite

Signals

- Yellow, orange, or red 1x1 round plates for excitatory signals
- Blue or dark blue 1x1 round plates for inhibitory signals
- Purple or transparent pieces for dream/replay signals

Base

- One large baseplate or several connected plates
- Optional: labels made from paper, tape, or small LEGO signs

Recommended Color Code

- Orange or yellow: excitatory neurons
- Blue: inhibitory neurons
- Green: sensory input
- Red or bright yellow: action potential
- Purple: memory or dream replay signal
- Gray or black: inactive connections
- White or tan: myelin-like insulation on long axons

Network Layout

Build a small network with 6 neurons:

- E0: excitatory input neuron
- E1: excitatory input neuron
- E2: excitatory middle neuron
- E3: excitatory output-path neuron
- I4: inhibitory control neuron
- I5: inhibitory control neuron

Suggested Layout on Baseplate

Place the neurons roughly like this:

E0        E2        I5

E1        I4        E3        OUT

You can also arrange them as:

Input side -> middle processing layer -> output side

Step 1: Build the Base

1. Place a large baseplate on a flat surface.
2. Leave open space on the left for input neurons.
3. Leave open space in the middle for processing neurons.
4. Leave open space on the right for the output neuron.
5. Optional: add a title label: "Neuron Network."

Step 2: Build the Soma for Each Neuron

For each neuron:

1. Place a 2x2 round brick, 2x2 round plate, or small circular build on the base.
2. Use orange/yellow pieces for excitatory neurons.
3. Use blue pieces for inhibitory neurons.
4. Add one transparent round stud on top to represent activation.

Build these somas:

- E0
- E1
- E2
- E3
- I4
- I5
- OUT

Step 3: Add Dendrites

For each soma:

1. Attach 3 to 5 short branches around the soma.
2. Use short bars, clips, small plates, or hinge pieces.
3. Dendrites should point toward possible incoming connections.
4. Keep them shorter than the axons.

Explanation

Dendrites receive incoming signals from other neurons.

Step 4: Add Axons

For each neuron except OUT:

1. Attach a longer branch extending away from the soma.
2. Point the axon toward another neuron.
3. Use longer plates, rods, bars, or connected small plates.
4. Add a small round stud or cone at the end as the axon terminal.

Explanation

Axons carry outgoing signals away from the neuron.

Step 5: Build Synaptic Connections

Create these connections:

1. E0 -> E2
2. E1 -> E2
3. E1 -> I4
4. E2 -> E3
5. E2 -> I5
6. I4 -> E3
7. I5 -> OUT
8. E3 -> OUT

How to show a synapse:

1. End the axon close to the next neuron's dendrite.
2. Leave a small gap between them.
3. Put a small round piece at the axon end.
4. Put another small round piece on the receiving dendrite.

Explanation

The small gap represents the synaptic cleft. A signal crosses this gap chemically or electrically.

Step 6: Mark Excitatory and Inhibitory Pathways

For excitatory connections:

- Use orange, yellow, or red pieces along the connection.
- These signals increase the chance that the next neuron fires.

For inhibitory connections:

- Use blue pieces along the connection.
- These signals reduce or block the chance that the next neuron fires.

Suggested pathway colors:

- E0 -> E2: orange
- E1 -> E2: orange
- E1 -> I4: orange
- E2 -> E3: orange
- E2 -> I5: orange
- I4 -> E3: blue
- I5 -> OUT: blue
- E3 -> OUT: orange

Step 7: Add Signal Tokens

Create small movable signal tokens:

- 4 orange/yellow 1x1 round plates for excitatory spikes
- 2 blue 1x1 round plates for inhibitory spikes
- 2 purple transparent pieces for memory or dream replay

Place the signal tokens at the start of E0 and E1.

Step 8: Add a Threshold Marker

Near each soma, place a small stack of 3 studs or plates.

Example:

- 0 studs = resting
- 1 stud = weak input
- 2 studs = near threshold
- 3 studs = neuron fires

When a neuron receives an excitatory signal, add one stud to its activation stack.

When a neuron receives an inhibitory signal, remove one stud or place a blue token beside it.

When the stack reaches 3 studs, the neuron fires and sends a signal down its axon.

Step 9: Manual Interaction Rules

Use the model as a playable simulation.

Rule 1: Excitatory input

Move an orange/yellow signal token from one neuron to the next.

When the token reaches a soma:

- Add 1 activation stud.
- If the soma reaches 3 activation studs, it fires.
- Move a new orange/yellow token down its axon.

Rule 2: Inhibitory input

Move a blue signal token from an inhibitory neuron to the next neuron.

When the token reaches a soma:

- Remove 1 activation stud.
- Or place a blue blocker token beside the soma.
- The neuron must clear the blocker before firing.

Rule 3: Firing

When a neuron fires:

1. Flash it by placing a transparent stud on top.
2. Move a signal token along its axon.
3. After firing, reset its activation stack to 0 or 1.

Rule 4: Synaptic delay

At each synapse, pause the signal for one turn before it moves to the next dendrite.

Rule 5: Refractory period

After a neuron fires, place a gray token on it for one turn.

A neuron with a gray token cannot fire again until the next turn.

Step 10: Run a Basic Signal Round

Round 1: Sensory Input

1. Put orange signal tokens at E0 and E1.
2. Move E0's signal toward E2.
3. Move E1's signal toward E2.
4. Add activation studs to E2.
5. If E2 reaches threshold, it fires.

Round 2: Propagation

1. Move E2's signal toward E3.
2. Move another E2 signal toward I5.
3. E3 becomes more active.
4. I5 prepares to inhibit OUT.

Round 3: Inhibition

1. Move I5's blue signal toward OUT.
2. If OUT has activation studs, remove one.
3. This shows inhibition controlling the output neuron.

Round 4: Output

1. Move E3's orange signal toward OUT.
2. If OUT reaches threshold, it fires.
3. Place a bright transparent stud on OUT to show network output.

Step 11: Add Learning

To show learning, strengthen connections that are used repeatedly.

After a connection is used 3 times:

1. Add an extra orange or yellow plate along that connection.
2. Make the connection physically thicker.
3. Let that connection count as 2 activation points instead of 1.

Example:

If E2 -> E3 is used repeatedly, strengthen it. Later, one signal from E2 may bring E3 closer to firing faster.

Step 12: Add Dream or Replay Mode

Dream mode means the network replays earlier signal paths without new outside input.

Instructions:

1. Remove the green sensory input tokens.
2. Place purple tokens on pathways that were active before.
3. Move the purple tokens through the network.
4. Let repeated learned paths glow or activate again.
5. Some paths may recombine into new routes.

Example Dream Replay

1. Purple token starts at E0.
2. It moves to E2.
3. E2 activates both E3 and I5.
4. E3 activates OUT.
5. I5 partially suppresses OUT.
6. The network replays a memory-like signal pattern.

Step 13: Add Labels

Use small paper labels or LEGO sign pieces:

- Soma
- Dendrite
- Axon
- Synapse
- Excitatory signal
- Inhibitory signal
- Threshold
- Refractory period
- Learning
- Dream/replay mode

Step 14: Optional Advanced Features

Feature 1: Myelin

Add white or tan pieces along long axons. These represent myelin sheath segments.

Rule:

- Signals move faster along myelinated axons.
- Skip one extra space per turn on myelinated axons.

Feature 2: Signal Strength

Use stacks of different heights:

- 1 stud = weak signal
- 2 studs = medium signal
- 3 studs = strong signal

Feature 3: Network Noise

Add one random token each round to a random neuron.

This represents spontaneous activity.

Feature 4: Plasticity

Allow connections to weaken if unused.

Rule:

- If a connection is unused for 3 rounds, remove one strengthening piece.

Feature 5: Output Decision

Let OUT represent a decision.

Examples:

- OUT fires = movement
- OUT stays quiet = no movement
- OUT fires after inhibition = controlled response

Final Model Description

This LEGO neuron network shows how signals enter a neural circuit, accumulate in neuron bodies, cross synapses, trigger firing, travel through axons, activate or suppress other neurons, and produce an output. Excitatory pathways increase activity, inhibitory pathways control activity, repeated pathways can strengthen through learning, and dream/replay mode shows stored activity patterns moving through the network without new input.
