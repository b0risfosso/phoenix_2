Octant Bird Dashboard: AI Flight Pattern Lab

This is a self-contained HTML game for itch.io.

Upload:
1. Create a new itch.io project.
2. Set Kind of project to HTML.
3. Upload octant_bird_dashboard_ai_game.zip.
4. Check "This file will be played in the browser."
5. Recommended viewport: 1280 x 720.

Main interaction:
Use the dashboard sliders to tune bird flight parameters, then press Play Round.
Rounds are longer than the previous version and can be tuned from 240 to 1200 steps.

AI Autoplay:
Enable AI Autoplay to let the game repeatedly run rounds and tune parameters between rounds.
The AI controller adjusts:
- steering
- wander
- turn rate
- chaos
- hit radius
- retarget time
- axis bonus
- coverage pull
- max speed
- energy saving
- round duration
- preset selection

AI goals:
- visit more octants
- cross more axes
- preserve energy
- increase loops/curvature when movement is too direct
- improve target hits when targets are missed

Dashboard parameters:
- Round steps
- Sim speed
- Max speed
- Steering
- Wander
- Turn rate
- Chaos
- Hit radius
- Retarget time
- Axis bonus
- Coverage pull
- Radial limit
- Energy saving
- Wind X/Y/Z
- Zoom
